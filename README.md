# codealpha_car-price-prediction
Predicted used car prices using the real Kaggle dataset (301 records). Compared Linear Regression, Random Forest, and Gradient Boosting using Scikit-learn. Gradient Boosting achieved R²=0.97, MAE=0.51L. Features: car age, present price, KMs, fuel type. Libraries: Pandas, Scikit-learn, Matplotlib, Seaborn.
